# Spacing & Layout

Breakpoints and container widths also live in `src/styles/Theme.ts`, under `breakpoints` and
`widths`. Both themes share the same values — light/dark only changes colors, never layout — so
this page reads from `lightTheme` alone.

## Breakpoints

Used as `max-width` media query thresholds throughout the container and layout components — e.g.
`@media (max-width: theme.breakpoints.lg)`.
