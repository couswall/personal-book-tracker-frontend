# Colors

Every color used in the app comes from `src/styles/Theme.ts` — one value for `lightTheme`, one for
`darkTheme`. Components never hardcode colors; they read `props.theme.colors.*`, so switching
theme (see the sun/moon toggle in the toolbar above) swaps every value on this page automatically.

If you need a new color, add it to **both** themes in `Theme.ts` first, then reference it from a
component — don't hardcode a hex value directly in a component's styles.
